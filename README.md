# 🎯 Student Placement Tracker

A simple, responsive web app to help students manage and track their placement journey — applications, interview stages, and skills, all in one dashboard.

🔗 **Live Demo:** _(add your GitHub Pages / Netlify link here)_

## ✨ Features

- 📊 **Dashboard** – Real-time stats: total applications, shortlisted, interviews, and skills count
- 👤 **Student Profile** – Save name, branch, skills, and resume/portfolio link
- ➕ **Application Tracker** – Add companies with role and status
- 🔄 **Status Updates** – Update application status directly (Applied → Shortlisted → Interview → Selected/Rejected)
- 🔍 **Search & Filter** – Quickly find applications by company or status
- 📈 **Visual Chart** – Bar chart showing status-wise breakdown
- ⬇️ **CSV Export** – Download your application data anytime
- 🌙 **Dark Mode** – Toggle between light and dark themes
- 💾 **Persistent Storage** – All data saved in browser localStorage (no backend needed)
- 📱 **Fully Responsive** – Works smoothly on mobile and desktop

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling, responsive design, dark mode
- **JavaScript (Vanilla)** – Logic, DOM manipulation, localStorage
